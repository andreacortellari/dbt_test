Welcome to my `dbt_test` repository! 

This is where I store all the code generated while learning how to use DBT. Most of what you see here is 1:1 with the instructions included in the https://learn.getdbt.com/learn/course/dbt-fundamentals course, with a little additional seasoning to adapt the project to my palate.

You can check what it is exactly that I do on https://andreacortellari.github.io/.

## Mt Toolkit
For this project, I have used:
- *DBT Studio*, where the magic happens.
- *GitHub*, where my code is stored. Commits are code-versioned and merged with clear Pull Requests. (And yes, it is a solo project, so I PRed and merged my own code. YOLO) 
- *BigQuery*, where my dataset lives.
